# Causal Studio

A React + FastAPI causal-design support dashboard using RAG, LLM orchestration, and deterministic validation.

## Planned Tech Stack

- React + Vite
- FastAPI
- SQLite
- ChromaDB
- LangChain
- LangGraph
- LangSmith later

## Important Rule

The LLM recommends and explains, but deterministic Python validation checks causal roles, timing, graph structure, and claims.

Causal Studio is a causal-design support tool. It must not present causal conclusions as proven, and it is not a diagnostic tool or treatment-decision system.
